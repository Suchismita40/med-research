# Support & Community

Thank you for exploring the **Private Medical Research Data Exchange** on Midnight!

## Getting Help
- **Issues**: If you encounter bugs or have questions, please open an issue in the repository.
- **Midnight Documentation**: Visit [docs.midnight.network](https://docs.midnight.network) for protocol documentation and tutorials.
- **Discord**: Join the official Midnight Discord community for developer support.

## Security Disclosures
If you discover a security vulnerability, please report it privately to the maintainers rather than opening a public issue.
